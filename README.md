# Homebrew Tap for Tengga

Official Homebrew tap for [Tengga](https://github.com/yolandaihsan17/tengga) — the lightweight, surgical Git diff reviewer desktop app for macOS, Windows, and Linux.

## Installation

Install Tengga via Homebrew Cask:

```bash
brew install --cask yolandaihsan17/tengga/tengga
```

Or tap this repository first:

```bash
brew tap yolandaihsan17/tengga
brew install --cask tengga
```

## Updating

To update Tengga to the latest version:

```bash
brew upgrade tengga
```

## Uninstalling

```bash
brew uninstall --cask tengga
```
